## Relance 1.0.0 : première version

Relance est une application de bureau pour suivre ses candidatures (alternance, stage, emploi) et ne plus oublier de relancer. Elle fonctionne entièrement hors ligne : aucune donnée ne quitte votre ordinateur.

### Points clés

- **Tableau de suivi** en six étapes (À postuler, Envoyée, Relancée, Entretien, Offre, Refusée), avec glisser-déposer.
- **Rappels de relance** : délai réglable, actions classées en retard / aujourd'hui / 7 prochains jours, badge dans la navigation.
- **Messages prêts à copier** pour relancer après une candidature ou un entretien, à partir de modèles personnalisables.
- **Historique daté** de chaque candidature, fiche complète (contact, lien, notes, prochaine action).
- **Bilan** : taux de réponse, entretiens, délai moyen de réponse, rythme hebdomadaire et sources les plus efficaces.
- **Sauvegarde / restauration JSON** et **export CSV**.
- Thème clair ou sombre, interface Material You.

### Quel fichier télécharger ?

| Système | Fichier | Pour qui |
|---|---|---|
| Windows | `Relance-Setup-1.0.0.exe` | Installation classique, recommandée |
| Windows | `Relance-1.0.0-portable.exe` | Sans installation (clé USB, poste sans droits admin) |
| Linux | `Relance-1.0.0-linux-x86_64.AppImage` | Toutes distributions : `chmod +x` puis lancer |
| Linux | `Relance-1.0.0-linux-amd64.deb` | Debian, Ubuntu et dérivées : `sudo apt install ./Relance-1.0.0-linux-amd64.deb` |

> L'exécutable Windows n'est pas signé : si SmartScreen s'affiche, cliquez sur **Informations complémentaires** puis **Exécuter quand même**. Les fichiers sont compilés par GitHub Actions à partir du code public du dépôt.
